# Clean sotkanet Cache

Delete all .rds files from the sotkanet cache directory.

## Usage

``` r
sotkanet_clean_cache(cache_dir = NULL)
```

## Arguments

- cache_dir:

  A path to the cache directory. If \`NULL\` (default) tries to clean
  default temporary cache directory.

## Examples

``` r
if (FALSE) { # \dontrun{
SotkanetCleanCache()
} # }
```
