# Writes the sotkanet data.frame in datapackage form

A function that turns the data.frame into a datapackage with the
metadata added in.

## Usage

``` r
write_frictionless_metadata(indicators, data)
```

## Arguments

- indicators:

  Dataset identifier

- data:

  The sotkanet data.frame object

## Value

datapackage
